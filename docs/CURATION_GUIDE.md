# Curation guide

Review each record in `data/photo-inventory.json`. Decide publication independently from archive inclusion. Add titles, public dates, public location and Condition assignments only where supported by authoritative context. Never classify from visual genre alone. Record manual decisions in `data/curation.json`; these decisions take precedence over future scans.

## Portfolio standard

The home page is an authored portfolio sequence, not a chronological feed. Every frame must add a distinct visual argument and meet the following criteria:

- recognisable point of view and intentional framing;
- controlled light, colour, focus and spatial depth;
- visual or emotional tension beyond a merely descriptive record;
- dialogue with the images immediately before and after it;
- no repetition of subject, composition or narrative function;
- an arresting opening, sustained rhythm and a memorable final gesture.

The current ten-image sequence demonstrates, in order: light, scale, gesture, transition, stillness, geometry, colour, human presence, landscape and enclosure. It was edited independently of filenames and capture dates.

This standard draws on [World Press Photo's judging criteria](https://www.worldpressphoto.org/contest/judging-process)—creativity, technical skill, visual style and story edit—and [LensCulture's guidance on sequencing](https://assets.lensculture.com/static/guides/pdf/LensCulture_Gallery_Guide_2024.pdf), which treats a sequence as a deliberate journey whose images relate to their neighbours.

## Interface fidelity

Typography, spacing and image ratios follow `website_V3`: 8–11 px utility/body text, a 30 px desktop hero title, a 72 px desktop header, hairline borders and a five-column image rhythm. Responsive rules retain the same hierarchy at 850 px and 420 px breakpoints instead of introducing a different mobile design.
