# Archive system

The source archive, interpretive Conditions and public publication are independent layers. Archive IDs are stable `TPC-00001` identifiers mapped to content hashes. Automated scans preserve manual overrides and default every decodable new photograph to retained `REVIEW`; ingestion never assumes that an ordinary subject or technical imperfection makes a photograph invalid. Classification uses `FEATURE`, `SUPPORTING`, `ARCHIVE`, `REVIEW` and reversible `REJECT`. Public pages curate only from explicitly chosen records, while every retained original remains recoverable. Source paths and private metadata are internal only; public pages use generated derivatives and stable IDs.
